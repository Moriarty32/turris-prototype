# Туррис — демонстрационный сайт

Многостраничный прототип по согласованной архитектуре и дизайн-референсу главной страницы.

**Сайт:** https://moriarty32.github.io/turris-prototype/

## Что реализовано

- 109 HTML-страниц на 22 типах страниц, четыре московских отеля и 21 категория номера.
- Предложения, семьи, командировки, группы, длительное проживание, справка и 16 материалов гида.
- Выбор дат, взрослых и возраста детей; сохранение контекста и выбранной категории в пределах вкладки.
- Сравнение объектов, фильтры гида, поиск, галерея, адаптивное меню и двухэтапная демонстрация групповой заявки.
- Статический HTML, мобильная версия, семантические заголовки, noindex для всего прототипа.

Это демонстрация: нет реального наличия, цен, платежей, отправки заявок или CRM. Оформление брони доступно по явному переходу на официальный сайт. Формы не сохраняют и не передают персональные данные; для проверки используйте вымышленные данные.

## Изображения

Сначала определены блоки, размеры и кадрирование в `docs/image-plan.json`. Четыре используемые иллюстрации созданы встроенным Imagegen; размер каждой проверен: **1536×1024 px**. Финальный первый экран использует `assets/hero-room-v2.png`, исходный вариант сохранён отдельно. Промпты и уточнение света включены в план изображений.

25 фотографий фасадов и категорий получены с официальных страниц `turris.online`; источники записаны в `data/asset-sources.json`. Эти фотографии не объявляются изображениями с открытой лицензией. Иллюстрации концепции помечены в интерфейсе и не подтверждают реальные свойства номера.

## Сборка и проверка

```powershell
python -m pip install -r requirements.txt
python scripts/build.py
python scripts/serve.py 4173
```

Открыть http://127.0.0.1:4173/turris-prototype/ . Сгенерированный сайт находится в `dist/`.

В другом терминале, при наличии Chromium для Playwright:

```powershell
python -m playwright install chromium
python scripts/qa.py
```

Проверки: все локальные ссылки и изображения, 109 страниц, один H1, noindex, 22 типа страниц в desktop/mobile, отсутствие горизонтального переполнения, даты/гости/категория, форма группы, поиск и фильтры. Результаты локально в `.qa/`.

## Публикация

GitHub Pages использует статическую ветку `gh-pages`, собранную из `dist/`. Основная ветка содержит исходники. Перед обновлением пересобрать и проверить изменённые сценарии.

```powershell
git subtree split --prefix dist -b deploy-next
git push origin deploy-next:gh-pages
```

Путь `/turris-prototype` задан в `scripts/build.py`. Перед production-переносом заменить демонстрационные формы, подключить официальную интеграцию бронирования, утвердить факты/условия/юридические документы, проверить изображения, canonical, sitemap и индексацию.
